# fullstack_developer_capstone

## Project Name

**fullstack_developer_capstone**

## Repository Name

**xrwvm-fullstack_developer_capstone**

## Project Description

This project is a full-stack car dealership application developed as part of the Full Stack Developer Capstone project.

The application provides a web interface for browsing car dealerships, viewing dealership information and reviews, registering users, logging in and out, and submitting dealership reviews.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Python
- Django
- REST APIs
- Node.js
- Docker
- Kubernetes
- GitHub Actions
- IBM Cloud

## Application Features

- View car dealerships
- View dealership details
- View dealership reviews
- User registration
- User login and logout
- Submit dealership reviews
- Review sentiment analysis
- Responsive frontend
- Backend REST APIs
- CI/CD workflow using GitHub Actions
